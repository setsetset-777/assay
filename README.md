# Assay

Assay helps agencies and service providers to clarify client needs early in the beginning of a project. It speeds up oroject kick-off and reduce ambiguity in the definition of the specifications.

## Development

Run:
```
pnpm compose:up
```
It will spin the needed docker containers for development via compose.
